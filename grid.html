CHAPTER I

Begin the Voyage

Before we can guide the crew, we need to prepare the ship's deck with a Grid.

The Grid Crew

CSS Grid is a layout system designed to arrange elements in rows and columns.

Unlike a normal block layout, Grid gives us a structured space where we can control both horizontal and vertical placement.

We start by giving the parent container:

display: grid

This tells the browser: “This container is now a Grid.”

Its direct children become grid items. These are the elements that Grid will arrange for us.

Once the container becomes a Grid, we can define columns, rows, gaps, and positions.

Think of it as drawing the ship's deck. Once the deck is mapped, every sailor can have a place to stand.

CHAPTER II

Draw the Map

A Grid is built from columns and rows. Now we decide how many tracks our deck should have.

Columns & Rows

Grid lets us define the structure of the container before we decide where individual items go.

grid-template-columns

This property defines the columns of the grid. 

grid-template-columns: 1fr 1fr 1fr;

This creates three equal columns.

Three sailing lanes across the deck, ready for the crew.

grid-template-rows

This property defines the rows of the grid. 

grid-template-rows: 100px 100px;

This creates two rows, each 100 pixels tall.

Two levels on the deck, one above the other.

repeat()

When several tracks have the same size, repeat() keeps the rule shorter. 

grid-template-columns: repeat(3, 1fr);

This means the same thing as writing: 

1fr 1fr 1fr

Experiment

Change the number of columns in the terminal. Try repeat(2, 1fr) and then repeat(4, 1fr).

CHAPTER III

Share the Space

A good deck needs balanced space. Grid gives us several ways to control the size of its tracks.

fr, px, and minmax()

Grid tracks can use different units. The fr unit means a fraction of the available space.

1fr 1fr 1fr

Three equal fractions give each column an equal share of the available space. 

grid-template-columns: 1fr 1fr 1fr;

The deck is divided into three equal lanes.

1fr 2fr 1fr

The middle column receives twice as much of the available fractional space as each outer column. 

grid-template-columns: 1fr 2fr 1fr;

The center of the deck gets a wider sailing lane.

minmax()

minmax() lets us give a track a minimum and maximum size. 

grid-template-columns:
    minmax(120px, 1fr) 1fr 1fr;

The first column cannot become smaller than 120px, but it can grow when space is available.

Even when the sea gets narrow, one sailing lane keeps enough room.

Try different proportions

Change 1fr 2fr 1fr to 2fr 1fr 1fr or 1fr 3fr 1fr.

CHAPTER IV

Leave Room to Sail

Once the grid is built, we can control the space between its rows and columns.

gap

The gap property creates space between grid items without adding margins to every item.

gap 

gap: 20px;

This creates a 20 pixel gap between both rows and columns.

Leave enough sea between every sailor.

row-gap

Controls only the space between rows. 

row-gap: 30px;

Give the crew more room between the decks.

column-gap

Controls only the space between columns. 

column-gap: 10px;

Keep the sailing lanes separated.

Align the whole grid

Grid can also position the grid tracks inside the available container space using justify-content and align-content.

These affect the grid as a whole, not the individual items.

Experiment

Try changing the gap to 5px, 30px, or 50px.

Then try separate row and column gaps.

CHAPTER V

Claim Your Place

Grid becomes powerful when we decide exactly where an individual item should begin and end.

grid-column & grid-row

Every grid item sits between grid lines. We can use those lines to make an item occupy one or several cells.

grid-column 

.hero:first-child {
    grid-column: 1 / 3;
}

The first item starts at column line 1 and ends at column line 3, so it spans two columns.

One sailor claims two sailing lanes.

grid-row 

.hero:first-child {
    grid-row: 1 / 3;
}

This makes the item span two rows.

One sailor claims space across two decks.

span

Instead of writing the ending line number, we can say how many tracks the item should span. 

grid-column: span 2;

This makes the item occupy two columns from its current position.

Place the crew

Try changing the first hero from one cell to grid-column: 1 / 3.

Then experiment with grid-row.

CHAPTER VI

Give Each Sailor a Command

The grid can have shared rules, but individual items can also receive their own instructions.

Control One Item

Grid has properties that let one item control its own position, alignment, or area.

justify-self

Controls the horizontal position of one grid item inside its grid area. 

.archer {
    justify-self: end;
}

Try start, center, end, or stretch.

align-self

Controls the vertical position of one grid item inside its grid area. 

.archer {
    align-self: center;
}

One sailor can move inside their own assigned space.

grid-area

grid-area can place an item using row and column lines. 

.archer {
    grid-area: 1 / 2 / 3 / 4;
}

This places the item from row line 1 to 3 and column line 2 to 4.

The captain can give one sailor a very specific place on the map.

Now experiment

Change one property at a time, run the code, and watch how only the selected item responds.

CHAPTER VII

Sail Every Screen

A real Grid should adapt to different screen sizes. Let's make our layout responsive.

Responsive Grid

A fixed number of columns can work well on a large screen, but the same layout may become crowded on a phone.

CSS Grid can create responsive columns that adapt automatically to the available width.

auto-fit + minmax() 

.crew {
    display: grid;
    grid-template-columns:
        repeat(auto-fit, minmax(120px, 1fr));
}

The browser creates as many columns as can fit, while each column stays at least 120px wide.

When the sea gets wider, more sailors can stand side by side. When it gets narrow, they rearrange.

@media — React to screen size

We can also use a media query when we want a specific layout at a specific screen width. 

@media (max-width: 600px) {
    .crew {
        grid-template-columns: 1fr;
    }
}

Try the viewport

Use the DESKTOP and MOBILE buttons to change the preview size.

Then experiment with minmax(), auto-fit, and the media query.

Put it all together

Responsive Grid is still the same Grid system. We are simply changing the number and size of tracks when the available space changes.

This is what makes Grid useful for real websites: the layout can adapt instead of forcing every item into one fixed arrangement.
