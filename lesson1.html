CHAPTER I

Every Element Is a Box

Before we set sail with Flexbox, we need to understand the things we are trying to arrange.

Welcome Aboard

Almost everything you see on a webpage is an HTML element.

A heading, a paragraph, a button, an image, or a div may look completely different, but CSS treats each element as a box.

Think in boxes

Every element takes up space on the page. 

<div>
    My first box
</div>

CSS lets us control that box: its size, its space, its border, and its position.

Before you can arrange the crew, you need to know what each sailor is standing on.

What should you notice?

The box itself is the element. The text inside it is its content.

In the next chapters, we will learn how CSS controls the space around that content.

CHAPTER II

Meet the Box Model

Every CSS box is made of several layers. Let's open it up.

Four Layers

The CSS Box Model describes the different parts of an element.

From the inside moving outward, we have:

Content

The actual thing inside the element — text, an image, or another element.

Padding

Space between the content and the border.

Border

The visible edge surrounding the padding and content.

Margin

Space outside the border, separating this box from others.

Remember the order: Content → Padding → Border → Margin.

Put the layers together

Think of the box like a treasure chest. The content is the treasure, padding gives it room, the border surrounds it, and margin keeps other chests away.

CHAPTER III

Give the Crew Room

Padding creates space inside your box.

Padding — Space Inside

Padding is the space between the content and the border of an element.

padding 

.box {
    padding: 20px;
}

This adds 20 pixels of space around the content on all four sides.

Increase the value and the content moves farther away from the border.

Padding is space INSIDE the box.

Different sides 

.box {
    padding-top: 30px;
    padding-right: 10px;
    padding-bottom: 20px;
    padding-left: 40px;
}

You can control each side separately when you need to.

Experiment

Try changing padding: 20px to 5px, 40px, or 60px.

CHAPTER IV

Build the Edge

The border marks where your box begins and ends.

Border — The Edge of the Box

A border surrounds the content and padding of an element.

border 

.box {
    border: 3px solid black;
}

The border has three important parts:

3px is the width. solid is the style. black is the color.

Border styles

Borders can have different styles such as: 

solid
dashed
dotted

Experiment

Change the border width or try dashed instead of solid.

The border is the wall around your ship's deck.

CHAPTER V

Leave Room to Sail

Now let's move outside the box.

Margin — Space Outside

Margin creates space outside an element's border.

Unlike padding, margin does not create space inside the box. It separates the box from other elements.

margin 

.box {
    margin: 20px;
}

This creates 20 pixels of space around the outside of the box.

Padding gives the sailor room inside. Margin gives the ships room between each other.

Separate sides 

.box {
    margin-top: 30px;
    margin-bottom: 20px;
}

Just like padding, you can control each side separately.

Padding or margin?

Ask yourself:

Is the space inside the box? → Padding.

Is the space outside the box? → Margin.

CHAPTER VI

Prepare the Fleet

You know what a box is. Now let's control its size and prepare to arrange the fleet.

Size Your Box

CSS gives us properties such as width and height to control the size of an element.

width and height 

.box {
    width: 220px;
    height: 120px;
}

Width controls how wide the box is, while height controls how tall it is.

Put everything together

You now know the basic pieces of a CSS box:

Content — what's inside.

Padding — space inside.

Border — the edge.

Margin — space outside.

Width & Height — the size.

But there is one problem...

Imagine we have three boxes.

What if we want them to sail side by side? 

┌─────────┐ ┌─────────┐ ┌─────────┐
│  Box 1  │ │  Box 2  │ │  Box 3  │
└─────────┘ └─────────┘ └─────────┘

Enter Flexbox

This is exactly the problem Flexbox helps us solve. 

.crew {
    display: flex;
}

Flexbox gives us a way to arrange and control boxes inside a container.
