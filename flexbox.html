CHAPTER I

Begin the Voyage

Before we can guide the crew, we need to turn the container into a Flexbox container.

The Flexbox Crew

Flexbox is a layout system designed to arrange elements inside a container.

Normally, block elements stack one underneath another. Flexbox lets us control how those elements are positioned, spaced, and aligned.

We start by giving the parent container:

display: flex

This tells the browser: “This container is now a Flexbox.”

Its direct children become flex items. These are the elements that Flexbox will arrange for us.

By default, flex items are placed next to each other in a row.

Think of it as preparing the ship's deck. Once the deck becomes a Flexbox, the crew can be arranged and given different positions.

What should you expect?

In the example, the three crew members start appearing in a row instead of being stacked vertically.

Try removing display: flex from the terminal and run the code. Then add it back. The difference should be immediately visible.

CHAPTER II

Choose Your Direction

A ship can change its course. So can a Flexbox layout.

The Main Axis

Once an element becomes a Flexbox container, its items are arranged along a direction called the main axis.

The flex-direction property decides which direction that axis follows.

row

This is the default direction. Items are placed from left to right.

The crew sails across the deck.

row-reverse

The items stay in a row, but their order is reversed.

The first item moves to the right and the last item moves to the left.

Same deck. New sailing direction.

column

Items are arranged vertically from top to bottom.

The crew now moves down the mast instead of across the deck.

column-reverse

Items are arranged vertically, but from bottom to top.

The direction is reversed compared with column.

Try the four directions

Change the value of flex-direction in the terminal.

Try: row, row-reverse, column, and column-reverse.

Run the code after each change and watch the crew follow the new main axis.

CHAPTER III

Arrange the Crew

Knowing the direction is only the beginning. Now we decide where the crew should gather.

justify-content

The justify-content property controls how flex items are distributed along the main axis.

If your crew is arranged in a row, this usually means controlling their horizontal position.

flex-start

Items gather at the beginning of the main axis.

With a normal row, this means they stay toward the left side.

The crew gathers at the beginning of the deck.

center

Items move together into the center of the available space.

The crew meets in the middle of the ship.

flex-end

Items gather at the end of the main axis.

In a normal row, they move toward the right.

space-between

The first item moves to the beginning and the last item moves to the end.

The remaining space is distributed evenly between the items.

The crew spreads across the whole deck, but nobody gets extra space at the edges.

space-around

Every item receives space around it.

This creates space on both sides of each item. The space at the edges is smaller than the space between two neighboring items.

space-evenly

The available space is divided equally between the items and the edges.

This creates equal gaps everywhere.

Everyone gets exactly the same amount of sea around them.

Set the crew's position

Start with flex-start in the terminal. Then replace it with each value you learned.

Run the code after every change and compare how the crew is distributed across the deck.

CHAPTER IV

The Cross Axis

Flexbox has another direction to control: the cross axis.

align-items

We already learned that justify-content controls the main axis.

align-items controls how the flex items are positioned along the cross axis.

When the direction is a row, the cross axis runs vertically.

stretch

Items stretch across the cross axis when their cross-axis size is not already set.

This is the default value.

flex-start

Items move toward the beginning of the cross axis.

With a row, this usually means toward the top.

center

Items are centered along the cross axis.

The crew lines up in the middle of the mast.

flex-end

Items move toward the end of the cross axis.

With a row, this usually means toward the bottom.

One crew member can disagree

align-self

Sometimes the whole crew should be aligned one way, but one particular item needs a different position.

That is what align-self is for. It overrides align-items for one specific flex item.

In the example, the whole crew is centered, but the hero is moved toward the start.

The crew follows the captain's orders, but one sailor has their own position.

Experiment

Change align-items: center to flex-start or flex-end.

Then change the hero's align-self value and watch how only that item reacts.

CHAPTER V

Make Room to Sail

A good crew needs space. Flexbox gives us simple tools for controlling it.

gap

The gap property creates space between flex items.

For example: 

gap: 20px;

means that Flexbox will place a 20 pixel gap between neighboring items.

Unlike adding margins manually to each item, gap is designed specifically for spacing items in a layout.

Think of it as leaving enough room between sailors so nobody steps on another sailor's feet.

Changing the gap

Try changing: 

gap: 20px;

to: 

gap: 5px;

or: 

gap: 40px;

A larger value creates more space between the crew members.

flex-wrap

What happens when there are too many items to fit on one line?

flex-wrap decides whether the items are allowed to move onto another line.

nowrap

This is the default. All items try to remain on a single line.

If there is not enough space, the items may shrink or overflow depending on the other CSS rules.

wrap

Items are allowed to move onto a new line when there is not enough room.

When one deck becomes too crowded, the crew moves onto the next deck.

Try it yourself

First change gap and observe the spacing.

Then change flex-wrap: nowrap to flex-wrap: wrap.

Run the code and make the preview smaller if needed to see the crew move onto multiple lines.

CHAPTER VI

Individual Powers

The whole crew can follow the same rules. But sometimes one flex item needs its own command.

Control One Item

So far, most of our properties have controlled the crew as a group.

Now we can give individual flex items their own instructions.

order — Change the position

Every flex item starts with an order value of 0.

Items with smaller order values appear earlier. Items with larger values appear later. 

.archer {
    order: -1;
}

Here, the archer gets -1, which places it before the items whose order is still 0.

Try changing -1 to 1 or 2. The archer will move after the other crew members.

Think of order as changing someone's place in the line.

flex-grow — Claim extra space

flex-grow controls how an item receives extra available space inside the container. 

.hero {
    flex-grow: 1;
}

A value of 0 means the item does not grow to take extra space.

A value greater than 0 allows it to grow.

Try changing: 

flex-grow: 1;

to: 

flex-grow: 2;

The item will receive a larger share of the available extra space compared with items with a smaller grow value.

The ship has extra room. How much of it does each sailor get?

flex-shrink — Give up space

Sometimes there is not enough room for every item at its preferred size.

flex-shrink controls how much an item is allowed to become smaller. 

.hero {
    flex-shrink: 1;
}

The default value is 1, meaning the item is allowed to shrink.

Try: 

flex-shrink: 0;

Now the item will not shrink because of Flexbox's shrinking process.

The ship is getting crowded. Who is willing to make themselves smaller?

flex-basis — Set the starting size

flex-basis defines an item's initial size along the main axis before remaining space is distributed. 

.hero {
    flex-basis: 150px;
}

If the crew is arranged in a row, this usually affects the item's starting width.

Try changing 150px to 250px.

The hero will begin with more space before Flexbox calculates how the remaining space should be distributed.

Before the crew settles into position, how much deck space does this sailor start with?

align-self — Move one item

align-self lets one flex item have a different alignment from the rest of the crew.

It overrides the container's align-items value for that particular item. 

.archer {
    align-self: flex-end;
}

Try: 

align-self: flex-start;

Then try: 

align-self: center;

Watch how only the archer changes position while the other crew members stay aligned.

The crew follows one formation, but one sailor can choose their own place.

CHAPTER VII

Sail Every Screen

A real website must work beyond one screen. Let's combine Flexbox with responsive design.

Responsive Flexbox

People can open a website on a large monitor, a laptop, a tablet, or a phone.

A layout that looks good on a wide screen may become crowded on a small one.

Responsive design allows us to change the layout depending on the available screen space.

Changing direction

A navigation bar might work well as a row when there is plenty of horizontal space. 

.navbar-demo {
    display: flex;
    flex-direction: row;
}

On a smaller screen, we can change the direction to a column. 

.navbar-demo {
    flex-direction: column;
}

The ship has a wide deck at sea, but when space becomes tight, the crew changes formation.

@media — React to screen size

A media query lets us apply CSS only when a certain condition is true. 

@media (max-width: 600px) {
    .navbar-demo {
        flex-direction: column;
    }
}

Here, the rule applies when the viewport is 600px wide or smaller.

On a large screen, the navigation remains in a row. On a smaller screen, it becomes a column.

Try the viewport

Use the DESKTOP and MOBILE buttons to change the preview size.

Then edit the media query in the terminal. Try changing 600px to another value and observe when the layout changes.

You can also experiment with flex-direction, gap, and align-items inside the media query.

Put it all together

Responsive layouts are not a completely different kind of Flexbox. They are simply Flexbox rules that change when the available space changes.

This is what makes Flexbox useful for real websites: the same layout can adapt to the screen instead of forcing everything into one fixed arrangement.
